# Быстрый старт

Инструкция по установке и первому запуску находится в [русском README](../README.ru.md#развёртывание).

## Настройка и ресурсы

Откройте [гайд по .env](CONFIGURATION.ru.md) для примеров подключения моделей и параметров запуска. Команды `--scale`, состав стартовых шести контейнеров и ориентир на 200 ГБ диска находятся в разделе [Железо и масштабирование](CONFIGURATION.ru.md#железо-и-масштабирование).

## Проверка сервисов

```sh
docker compose ps
docker compose logs --tail 100 backend worker inspect-worker
```

По умолчанию веб-интерфейс доступен на `127.0.0.1:8080`. Порт задаёт `FRONTEND_PORT`.

## Версии образов

Compose использует версии из [конфигурации](../docker-compose.yml) по умолчанию. Чтобы закрепить свои теги, поменяйте [.env.versions](../.env.versions) и передайте оба файла окружения.

```sh
docker compose --env-file .env --env-file .env.versions up -d --build --wait
```

## Остановка

```sh
docker compose stop
```

Тома загрузок, результатов, PostgreSQL и Redis доступны при следующем запуске. [Обновление существующей установки](../README.ru.md#обновление-существующей-установки)
