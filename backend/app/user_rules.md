1. **Большие отчёты запускайте вечером или ночью.** Модель общая для коллег. Днём большой файл может замедлить их работу и обработку вашего отчёта.

2. **Сначала проверьте результат на 20–50 строках.** Ограничьте число строк и откройте «Показать, что уйдёт в модель». Запускайте весь файл, когда результат вас устраивает.

3. **Делите большие файлы на части.** Предел загрузки — {{upload_limit_mb}} МБ. Для удобства берите примерно до 100 тыс. строк по периодам или темам — это рекомендация, а не предел.

4. **Загружайте только нужные данные.** Уберите лишние колонки, ФИО, телефоны и номера договоров. Проверьте предварительный просмотр: в нём видно, что получит модель.

5. **Следите за квотой.** Остаток — в блоке «Квота»; месячная квота обновляется 1-го числа по Москве. После пополнения нажмите «Продолжить». {{paused_policy}}

6. **Не запускайте один отчёт повторно без необходимости.** Повторная обработка может снова расходовать квоту. Частичный результат можно скачать в промежуточный файл.

7. **Проверяйте результат выборочно.** Модель может ошибаться. Перед выводами просмотрите часть строк и лист «Ошибки», если он есть.
