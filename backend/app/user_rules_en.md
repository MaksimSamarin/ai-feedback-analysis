1. **Schedule large analyses outside peak hours.** A large run can slow down other users sharing the same model.

2. **Start with 20–50 rows.** Use **Preview model input** to check the data and prompt. Run the full file once the sample output looks right.

3. **Split large files into batches.** The upload limit is {{upload_limit_mb}} MB. Around 100,000 rows per batch is a practical starting point.

4. **Send only the data you need.** Remove unnecessary columns, names, phone numbers, and account identifiers. Preview the model input to confirm what will be sent.

5. **Check your quota.** Monthly quotas reset on the first day of the month in Moscow. After the quota replenishes, select **Resume** to finish a paused report. {{paused_policy}}

6. **Reuse existing results.** Running the same analysis again may use more of your quota. Download an interim Excel file if you need the rows already processed.

7. **Review a sample of the output.** Check a few rows and the error sheet, if present, before using the results.

8. **Contact your group manager for help with access.** An administrator reviews requests from users who haven't selected a group.
